VOXEL WAVEFORMER
================

How to use:
1. Extract all files to a folder
2. Open index.html in a modern web browser
3. Click "Start Audio" to use microphone
4. Controls:
   - H: Toggle UI
   - Space: Start/Stop audio
   - 1-5: Change themes
   - F: Fullscreen
   - R: Record

Requirements:
- Modern browser (Chrome, Firefox, Edge)
- WebGL support
- Microphone (optional)
